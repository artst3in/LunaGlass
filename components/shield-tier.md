# Shield Tier

Visual frame around hex avatars indicating security posture. Five tiers by lit-node count in the Skill Tree.

## Tiers

| Tier | Nodes | Color | Token |
|------|-------|-------|-------|
| None | 0 | No frame | — |
| Bronze | 1 | Classic bronze | `shield-bronze` (#CD7F32) |
| Silver | 2-8 | Muted silver | `shield-silver` (#9AA4AD) |
| Gold | 9 | Pure gold | `shield-gold` (#FFD700) |
| Cyan | All | Brand cyan | `shield-cyan` (#00FFFF) |

## Design Logic

Bronze → Silver → Gold follows the standard medal climb. Cyan is the crown — the Aegis brand colour worn only by users who maxed every node. It reads as "this person IS Aegis" rather than a generic default. Unpainted (no frame) is the default for new users.

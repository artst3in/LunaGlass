# Navigation Bar

Bottom navigation using hex icons.

## Layout

Horizontal row of XS hex buttons. Fixed to bottom of screen.

| Property | Value |
|----------|-------|
| Background | `#0A1214` |
| Border top | 1px `#1A3A40` |
| Padding | 8px 16px |
| Item spacing | 16px |
| Icon size | XS (20px) hex |

## States

| State | Border | Fill | Label | Opacity |
|-------|--------|------|-------|---------|
| Active | `#00FFFF` | `rgba(0,255,255,0.1)` | cyan | 1.0 |
| Inactive | `#6A8A8A` | transparent | dim | 0.4 |

## Badge

Notification badge = small dot (6px) positioned at upper-right of hex. Color matches the notification type (cyan for info, red for urgent).
